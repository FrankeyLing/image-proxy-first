# 解码方式与依赖

正常路径使用随包预编译的 C++ 程序，无需 Python、编译器或联网。仅不支持的编解码器回退到 Python 3.10 及 Pillow。安装时可明确启用私有 `.venv`（`--with-python-fallback` 或 Windows `-WithPythonFallback`），仅这一可选步骤需要联网。相机高效格式和厂商原始格式需可选解码器。

代理去除相机元数据，透明区域铺白，可能改变色彩和位深。默认输入像素上限为 160,000,000，可用 `--max-input-pixels` 明确调整，不可默默解除限制。

## 普通图像

```text
proxy input.jpg
proxy multipage.tiff --frame 1
```

原生路径支持常见照片、位图及首帧动图；多页、容器高位深和其他不支持格式自动回退。页/帧序号从零开始。先处理方向标记，再按旋转后坐标裁剪。高位深单通道图像线性映射到 8 位显示范围，不用于数值测量。

## 手机高效格式与相机原始文件

前者需要可选 `pillow-heif`，后者需要可选 `rawpy`。安装器 `--extras`（Windows `-Extras`）明确安装两项；也可在已有私有环境内明确安装。是否支持具体设备取决于实际解码器，不能保证所有厂商格式。

```text
proxy input.dng --mode camera-raw
```

相机原始模式采用半尺寸解码和相机白平衡，不适用于猜测无头传感器数据。

## 无头工业传感器数据

必须由资料明确宽高、布局、头部偏移、行步长。支持单通道 8 位、单通道 16 位大小端、三通道红绿蓝/蓝绿红、四通道红绿蓝透明度。每行可有明确填充。默认拒绝尾随数据，除非明确 `--allow-trailing`。

```text
proxy sensor.raw --mode raw-gray16le --width 6000 --height 4000 --offset 0 --stride 12000
proxy frame.bin --mode raw-bgr24 --width 3840 --height 2160 --offset 128 --stride 11520
```

单通道高位深可同时给 `--black` 和 `--white` 指定显示区间，否则采用实际最小和最大值。恒定图像采用固定显示并记录区间。没有去马赛克功能；颜色滤阵数据只能在明确标记为灰度预览后按单通道容器读取。打包 10/12 位、专有压缩、浮点及多平面布局，须用经过验证的外部解码器，不能伪装为支持的布局。

## 视频

需已安装 `ffmpeg`，只提取明确时间的一帧，不把整片展开到上下文。

```text
proxy clip.mp4 --mode video --time 12.5
```

子进程只生成本地受限中间图像，不打印编码；失败则报错，不回退转发原视频或原始帧。视频内部解码可能使用较多内存，输出体积上限不是解码内存上限。
